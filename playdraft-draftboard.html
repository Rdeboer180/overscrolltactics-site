From spreadsheet to draft room.

Keep the header row exactly as it is. Add one draftable choice per row.

  1. Fill the sheet.Replace the example rows with your own choices. Asset title is required. Descriptor and Category are optional.
  2. Export a CSV.Save or export as CSV with the columns in this order: Asset title, Descriptor, Category. Keep the file in Files, iCloud Drive, or anywhere else your iPhone can open it.
  3. Import in PlayDraft.Open Custom, tap Create pack, then Import CSV. Review the choices, fix or remove any flagged rows, then save the pack and host it.

What the importer checks

Column or fileRule
Header rowExactly Asset title,Descriptor,Category, in that order. Capital letters don’t matter.
Every rowThree columns, even when Descriptor or Category is blank. Empty rows are skipped.
Asset titleRequired. 2–80 characters. Each title can appear only once, whatever its capitalization.
DescriptorOptional. Up to 160 characters, shown under the title.
CategoryOptional. Up to 40 characters, and up to 5 different labels across the board. “Snacks” and “snacks” count as one label. Labels add color only; nobody has to draft from each one.
Commas and quotesA value with a comma goes inside double quotes, and a quote inside it is doubled (""). Spreadsheet apps do this for you when they export.
FileA .csv file under 1 MB, with up to 500 choices. Extra spaces are trimmed.
ContentChoices that break the content rules are flagged so you can edit or remove them.
How many choices?

A room needs at least as many choices as players × picks per player. Rooms have 3–8 players and 3–7 picks each, so the smallest room needs 9 choices and the largest needs 56. You can save a pack with fewer and finish it later.

No spreadsheet? You can type or paste choices directly in the app, one per line. Using PlayDraft 2.2.0 or earlier? Those versions allow 3 categories. Need a hand? Visit PlayDraft support.
